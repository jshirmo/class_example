About

What this repository is for.

This site is served directly from the main branch using GitHub Pages. It started as a bare repository with only a README, and grew into a working static page — a simple example of the full loop from empty repo to a live, deployed site.

Demonstrations

Small, self-contained examples of how a page like this works — each one live on the page, with the code behind it.

1. Structure: HTML

Every element on this page is an HTML tag. A heading uses <h1>–<h6>, a paragraph uses <p>, and a link uses <a>.

This box is a link inside a paragraph.

<p>
  This box <a href="#demos">is a link</a>
  inside a paragraph.
</p>

2. Style: CSS

CSS changes how HTML looks without changing the content. Click the button to swap the swatch's background color by toggling a class.

.swatch { background: var(--accent); }
.swatch-alt { background: #16a34a; }

button.onclick = () =>
  swatch.classList.toggle('swatch-alt');

3. Behavior: JavaScript

JavaScript makes a page interactive. This button updates a number stored in memory each time it's clicked.

0 
let count = 0;
button.addEventListener('click', () => {
  count++;
  display.textContent = count;
});
